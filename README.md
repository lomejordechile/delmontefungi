## Despliegue en GitHub Pages

1. Subir todos los archivos al repositorio
2. Ir a **Settings > Pages**
3. Seleccionar rama `main`, carpeta `/root`
4. Guardar — el sitio estara disponible en `https://usuario.github.io/repositorio/`
